# Apelele Hair Collection - Web Development Project (Part 2)

Welcome to the **Apelele Hair Collection** project repository. This project is developed as part of the WEDE5020 web development coursework, focusing on semantic HTML5 page structure, custom CSS layouts, responsive design, and version control workflows using Git.

## Project Overview
Apelele Hair Collection is a modern, responsive web application and e-commerce concept showcasing premium hair products, styling collections, and customer care resources that all started as a side hustle for tuition fees. The application emphasizes accessibility, clean visual hierarchy, and seamless user experience across devices so customers can come to contact with the business through the website.

## Features
- **Semantic HTML5 Architecture:** Clean, accessible markup ensuring optimal screen reader compatibility and SEO performance.
- **Advanced CSS Layouts:** Custom styling utilizing modular CSS rules, flexible containers, and a cohesive, professional color palette tailored to the brand.
- **Responsive Design:** Optimized viewing experiences across mobile, tablet, and desktop viewports.
- **Interactive Wireframe Integration:** Built following structured single-page ASCII wireframes and architectural design documentation.
- **Git Version Control:** Maintained with clean commit histories, branching strategies, and detailed changelogs.

## Getting Started

### Prerequisites
To view and run this project locally, you will need:
- A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
- A local development environment or code editor (such as Visual Studio Code).

### Installation & Local Setup
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/ApeleleMayi/WEDE5020_Apelele_Hair_Collection.git
   ```
2. Navigate into the project directory:
   ```bash
   cd WEDE5020_APELELE_ONKE_MAYI_PART2
   ```
3. Open `index.html` in your preferred web browser or run it via a local development server (e.g., Live Server in VS Code).
